# AllanChain Tap

## How do I install these formulae?

`brew install allanchain/tap/<formula>`

Or `brew tap allanchain/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "allanchain/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
